# NAVER Mail — Claude 데스크톱 확장

Claude 데스크톱 앱의 채팅에서 네이버 메일을 검색·읽기·발송하는 확장입니다.
서버는 내 PC에서만 실행되고 네이버 IMAP·SMTP에 직접 연결합니다.

## 설치

1. Claude 데스크톱 앱에서 **설정 → 확장 프로그램**을 엽니다.
2. `.mcpb` 파일을 창에 끌어다 놓거나 더블클릭합니다.
3. 네이버 메일 주소와 **애플리케이션 비밀번호**를 입력하고 설치합니다.

준비물: 네이버 메일 환경설정에서 **IMAP/SMTP 사용함**, 네이버ID 보안설정에서 **2단계 인증**과 **애플리케이션 비밀번호**.
Node.js 를 따로 설치할 필요가 없습니다.

## 사용

- "네이버 메일 연결 상태 확인해 줘"
- "안 읽은 메일 5개만 요약해 줘"
- "홍길동님한테 '내일 2시 회의' 메일 보내 줘. 보내기 전에 미리 보여 줘"

계정을 바꾸려면 확장 프로그램 설정에서 값을 수정합니다.
첨부파일은 `~/.naver-mail-mcp/attachments` 폴더를 사용합니다.
